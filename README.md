## English

From the [**Releases**](https://github.com/SancioPanza88/psp-flix/releases) page download:

- **`PSP Flix.exe`** — search films & TV series, download them and convert them into PSP-compatible MP4.
- **`PSPThumbnailMaker.exe`** — create the `.THM` cover image so the PSP shows a preview instead of the generic white icon. Pick the video, extract a frame (or choose your own image) and press "Create thumbnail": the `.THM` file is saved next to the video.
- **`ffmpeg.exe`** + **`ffprobe.exe`** — required next to the two programs above (or have ffmpeg on your PATH). Download the `ffmpeg-git-essentials.7z` build from [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) and copy the two `.exe` files next to them.

Copy the `.mp4` (and its `.THM`) into the `VIDEO` folder of your PSP Memory Stick.

## Italiano

Dalla pagina [**Releases**](https://github.com/SancioPanza88/psp-flix/releases) scarica:

Copia il file `.mp4` (e il suo `.THM`) nella cartella `VIDEO` della Memory Stick della PSP.
